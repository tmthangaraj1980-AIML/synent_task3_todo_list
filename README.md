# ✅ To-Do List CLI

A simple command-line task manager built using Python.

This project was developed as part of the Synent Technologies Python Development Internship — Task 3.

---

# 📌 Project Description

The To-Do List CLI is a menu-driven Python application that helps users manage daily tasks directly from the terminal.

Users can:
- Add tasks
- View tasks
- Delete tasks
- Exit the application safely

This project demonstrates the fundamentals of Python programming through a real-time command-line application.

---

# 🎯 Objective

The objective of this project is to create a simple task manager using Python and understand important programming concepts such as:

- Lists
- Functions
- Loops
- Conditional statements
- User input handling
- Exception handling

---

# 🚀 Features

✅ Add new tasks  
✅ View all tasks

# 🔍 What is `git clone`?

`git clone` means copying a GitHub repository from the internet to your computer.

Example:

```bash
git clone https://github.com/username/todo-list-cli.git
```

This downloads the full project folder from GitHub to your local system.
